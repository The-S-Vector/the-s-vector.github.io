HTML Cheat Sheet

This is a simple HTML cheat sheet I use for quick reference and notes. This does not include all or even the basic ones just the ones I want to remember

HTML tags

HTML code Description
<h(1-6)> eg. <h(2)> Defines a heading level where 1 is the largest
<p> Defines a paragraph
<a href="url"> Defines a hyperlink, it defaults to same level domain but if you add the "/" it will go to the root domain
<img src="url"> Defines an image, the url can be a relative path (same level domain) or an absolute path (root). Advised by W3schools to use relative paths when possible as it allows for domain changes.

Metadata

Metadata is the information given to the browser so that it can understand and/or display the page correctly.

HTML code Description
<meta charset="UTF-8"> Defines the character encoding for the document. UTF-8 is the most common and recommended.
<meta name="description" content="..."> Provides a brief description of the page's content, often used by search engines.
<meta name="author" content="..."> Specifies the author of the document.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> Controls the page's dimensions and scaling on different devices.
