Welcome — how this site works

September 13, 2026 · 3 min read

Meta

This site is plain HTML and CSS, written by hand and edited in VS Code — no static site generator, no build step, no database. Every page you're looking at is one file you could open and read start to finish.

Notes like this one live as individual .html files inside notes/. To write a new one, I copy notes/template-post.html, write the article, and add a link to it at the top of the notes index. No plugins, no markdown converter — just a template and a list.

Why so plain?

Partly because it's genuinely all this site needs, and partly because every page here is meant to be readable as an example of plain HTML/CSS — see the coursework section in particular, which is written to be studied, not just used.
